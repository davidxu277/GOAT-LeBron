## B. 证据类 —— 简历和答辩最值钱的部分

### B1. 噪声带实测（不需要 API key）

同一份配置换 5 个随机种子跑，量出 GAUC 和 nDCG@5 各自的抖动幅度，分指标落盘，
喂给医生和复盘官。

代码里到处在用「噪声带」判「这个差距算不算真的」，但这个数从来没在 KuaiRand 上
量过一次。不量，「提升 0.003」说不清是本事还是运气。

### B2. 锁定集：整场只评一次的考场

现在只有训练集和验证集。Agent 跑 N 轮都在看验证集挑最好的一轮 —— 这个「最好」
里有一部分是挑出来的运气（多重比较）。要单独切一块，整场结束只评一次。
`agent/loop.py` 已经留了 `holdout_scores` 字段，没人往里写。

这是实验方法上的硬伤，比多涨 0.001 重要。

### B3. 真模型第一次跑（要 API key）

这条路一次都没跑过，是目前最大的未知。顺序：

1. 5 份假成绩单考四个角色，含两道陷阱题（干净数据不许硬编病、小样本数字不许当证据）
2. 过了再上小份真数据跑 3~5 轮
3. 崩在哪分诊：输出内容不对 → 改提示词；格式过不了校验 → 看校验是否过严

### B4. 对比实验：诊断驱动 vs 随机选卡（要 API key）

同轮数、同预算，一组让医生诊断后筛卡，一组随机选卡，比最终分数。

这是唯一能证明「这个 agent 的脑子有用」而不是「多试几次总能撞到」的实验。

### B5. 过程指标出一张表

从 `rounds.jsonl` 算：代码执行成功率（加试跑前 vs 加试跑后）、假设命中率
（判「猜对了」的占比）、每轮 token / 时间 / 估算花费。要先有 B3 的真跑数据。
